# API REST com Flask

Projeto de estudo de uma API REST feita com Flask, em Python, seguindo tutorial em vídeo.

## 📦 Requisitos

- Python 3.x
- Flask

## 🚀 Como rodar

```bash
# Criar e ativar o ambiente virtual
python -m venv venv
source venv/Scripts/activate    # Windows (Git Bash)
# ou: source venv/bin/activate  # Linux/Mac

# Instalar dependências
pip install -r requirements.txt

# Rodar a aplicação
python app.py
```
